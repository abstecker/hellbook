Hell in a Cell: Rust Edition

Round 10: The Undercard

The main event is over. The gate is green, the loopholes are closed, and every judge scores every fight. What's left are the bouts nobody bought a ticket for: things no tool in the gate checks, so only a human reading carefully will ever catch them.

The manifest points at the wrong repo

repository = "https://github.com/devplaybooks/rust_worlds_simplest_kata"

This kata lives at hell_in_a_cell_kata_rust_edition. The manifest still points at its ancestor, the World's Simplest Kata. crates.io would link to the wrong place, and so would cargo info and anything else that reads the metadata. Nothing fails. It's just wrong, quietly, forever.

Out of the ring

A few more things the gate will never see. They're outside what this book replays, but they're worth a look before you call the kata done:

  • Cargo.lock is in .gitignore. The comment in that file repeats old advice: commit the lock file for executables, ignore it for libraries. This package is both, and since 2023 Cargo's guidance is to commit it by default. A committed lock file makes CI builds reproducible.
  • The dev container is a museum piece. ubuntu:18.04 reached the end of its standard support in 2023. The matklad.rust-analyzer extension ID was retired years ago in favor of rust-lang.rust-analyzer, and terminal.integrated.shell.linux is a VS Code setting that no longer does anything.
  • cargo test --all. --all is a deprecated alias for --workspace. It still works, but it's the kind of thing that stops working on the day you least expect it.
  • dtolnay/rust-toolchain@master pins an action to a moving branch, so whatever lands on master runs in your CI with contents: read on your repo. That's a supply-chain risk worth weighing. Pinning to a commit SHA is the hardened option.

✍️ EDITOR: Decide which of these, if any, the kata intends as defects. If the dev container is meant to be fixed, it could become a real round, replayed like the others.

💡 LESSON: A green gate means that everything the gate checks is fine. It's silent about everything else. Know what your gate doesn't check.

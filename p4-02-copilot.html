Hell in a Cell: Rust Edition

CoPilot

In this corner... weighing in at several hundred billion parameters... Sam Altman's and Satya Nadella's purloined AI love child, currently infesting every Microsoft application it can sink its binary claws into...

GitHub will review your pull requests with CoPilot, and it will write them, too. So we handed the kata to CoPilot and let it open a pull request.

Its attempt is preserved on the copilot/make-code-green branch, as a single commit: "Fix build errors and bugs in lib.rs, main.rs, and Cargo.toml." CoPilot fought an earlier cut of the kata, one with a #![warn(clippy::pedantic)] line at the top of lib.rs, package version 0.1.2, and license = "GPL-3". None of those lines are on the scorecard, so this book replays CoPilot's edits, line for line, onto the kata as delivered in Part II. The result lives on a branch named copilot.

pub struct Hello;

/// The [Hello] project is a simple hello world program. It comes with two methods:
///
/// 1. `hello` - This method takes a `String` and returns `Hello, {name}!`.
/// 2. `hello_world` - A default method that returns `Hello, world!`.
///
/// ```
/// use worlds_simplest_kata::Hello;
///
/// let hello = Hello::hello("everyone".to_string());
/// assert_eq!("Hello, everyone!", hello);
///
/// ```
impl Hello {
    pub fn hello(name: String) -> String {
        format!("Hello, {}!", name)
    }

    pub fn hello_world() -> String {
        Hello::hello("world".to_string())
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn hello_world() {
        assert_eq!("Hello, world!", Hello::hello_world());
    }
}

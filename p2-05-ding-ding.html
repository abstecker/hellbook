That's the whole kata. Four files that matter, one mission:

Your turn: Make the GitHub Actions green

Fork the kata, enable GitHub Actions on your fork, and push until every job is green — both entries in the test matrix included.

  • Run the four commands from HINTS.md locally before you push. They are most of the referee, but not all of it.
  • Fix one thing at a time and re-run. The tools report problems in an order, and some problems hide behind others.
  • Don't delete a test, a doc test, or a job to make it pass. That isn't winning; that's bribing the referee.
  • Green isn't done. When you get there, reread every line one more time.

Fork the repository, then:

git clone https://github.com/abstecker/hellbook.git   # or your fork
git checkout step-002-kata
cargo check

Green means you did it. The answer is the next step.

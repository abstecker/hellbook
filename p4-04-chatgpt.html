The library comes out almost identical to Fable's: &str in, String out, #[must_use] on both, the format argument inlined, and the doc test fixed. It even writes Self::hello instead of Hello::hello, a small, idiomatic touch that nobody asked for.

Look at the first line of the doc comment, though:

💾 src/lib.rs · L3–L3 · step 015 of hellbook · on chatgpt · diff · browse

pub struct Hello;

/// The `Hello` project is a simple hello world program. It comes with two methods:
///
/// 1. `hello` - This method takes a name and returns `Hello, {name}!`.
/// 2. `hello_world` - A default method that returns `Hello, world!`.
///
/// ```
/// use worlds_simplest_kata::Hello;
///
/// let hello = Hello::hello("everyone");
/// assert_eq!("Hello, everyone!", hello);
///
/// ```
impl Hello {
    #[must_use]
    pub fn hello(name: &str) -> String {
        format!("Hello, {name}!")
    }

    #[must_use]
    pub fn hello_world() -> String {
        Self::hello("world")
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn hello_world() {
        assert_eq!("Hello, world!", Hello::hello_world());
    }
}

$> git checkout step-015-chatgpt

[Helo] didn't become [Hello]. It became `Hello`: backticks, not brackets. The broken link is gone because the link is gone. The Doc judge is satisfied, since there's nothing left to resolve, but the documentation lost the one cross-reference it had.

That's the difference between fixing an error and making the error go away. Here it costs almost nothing: the link pointed at the very type it was documenting. In a bigger codebase, "delete what the checker complains about" is how documentation rots, one green build at a time.

$> git checkout step-015-chatgpt

That's the settings file of a rustup installation: the agent's own toolchain home, created in its sandbox and committed along with the fix. It does no harm. But it tells you two things: the agent ran rustup, and so, almost certainly, cargo, and nobody, human or machine, looked at git status before committing. It's the coding equivalent of leaving your gloves in the ring.

How it fought

✍️ EDITOR: The narrative, from the transcript. Things worth watching for:

  • Why remove the link instead of fixing the typo? Did it notice Helo was a misspelling, or did it read "unresolved link" and reach for the quickest way to make the error disappear?
  • The .rustup-home directory. Did it set RUSTUP_HOME to a local directory because its sandbox couldn't write to the real one? Did it mention the file in its summary?
  • "Finished." Did it report what it had fixed, or just that it was done?
  • Did it read the workflow? Like Fable, it fixed the Clippy findings that a PR would never have shown.

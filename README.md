# Hell in a Cell: Rust Edition

**This repository is generated. Do not open pull requests here.**

Every commit in this repository was produced by replaying the book
[Hell in a Cell: Rust Edition](https://github.com/ImperialBower/bower/tree/main/books/hellbook).
Each tag (`step-001-kata`, and so on) is the state of the code at one round of
the match — including the rounds where the code is still on the canvas.

- `main` walks from the broken kata to a green gate, one round per commit.
- The other branches are the AI contenders' attempts, preserved as they
  handed them in.

Want to fight the kata yourself? Fork
[the original](https://github.com/devplaybooks/hell_in_a_cell_kata_rust_edition),
not this. This repo is the spoiler.

`make ci` runs the same four jobs as `.github/workflows/CI.yaml`, locally.

To change the code, change the book.

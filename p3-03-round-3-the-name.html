Hell in a Cell: Rust Edition

Round 3: The Name

hello__world has two underscores. Rust names functions in snake_case: all lowercase, words separated by one underscore. The compiler's non_snake_case lint flags anything else.

Did you know a double underscore is called a dunder? I learned that at a Central Ohio Python Users Group meeting. Python is full of them — __init__ is a "dunder init" — which is exactly why a Pythonista's fingers type them without asking.

Renaming a public function is never a one-file change. There are three call sites: the definition, the unit test, and the binary. Miss one, and you've traded a warning for an error.

💾 src/lib.rs · L20–L20 · L31–L31 · step 005 of hellbook · diff · browse

pub struct Hello;

/// The [Helo] project is a simple hello world program. It comes with two methods:
///
/// 1. `hello` - This method takes a `String` and returns `Hello, {name}!`.
/// 2. `hello_world` - A default method that returns `Hello, world!`.
///
/// ```
/// use worlds_simplest_kata::Hello;
///
/// let hello = Hello::hello("everyone".to_string());
/// assert_eq!("Hello, everyone.", hello);
///
/// ```
impl Hello {
    pub fn hello(name: String) -> String {
        format!("Hello,  {}!", name)
    }

    pub fn  hello_world() -> String {
        Hello::hello("wirld!".to_string())
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn hello_world() {
        assert_eq!("Hello, world!", Hello::hello_world());
    }
}

The doc comment already said hello_world, one underscore. The docs were right and the code was wrong. Remember that; it won't be the last time.

Notice the two spaces between fn and hello_world are still there. That's not our fight yet. Fix one thing at a time, and let the referee tell you what comes next.

At last, the code compiles under the referee's rules, and the tests actually run. Now they get to fail:

💡 LESSON: A rename is a refactoring, and a refactoring touches every caller. Let the compiler find them for you: rename the definition, build, and fix every error it hands you. That's the type system working for you.
